# فرانت‌اند سامانه راهین

نسخه بازطراحی‌شده رابط کاربری با حفظ هویت بصری فعلی و تمرکز ویژه روی Dark Mode و تجربه چت.

## اجرا

```bash
npm install
npm run dev
```

آدرس پیش‌فرض API:
`http://localhost:8000`

در صورت نیاز:
`VITE_API_BASE_URL=http://localhost:8000`

## امکانات این نسخه

- حفظ تم روشن فعلی: سرمه‌ای، آبی، فیروزه‌ای، بنفش و پس‌زمینه گرادیانی نرم.
- Dark Mode با طیف سرمه‌ای/آبی/بنفش، بدون استفاده از مشکی خالص و بدون invert ساده.
- اصلاح کنتراست متن‌ها و کنترل جداگانه رنگ سطوح، کارت‌ها، جدول‌ها، ورودی‌ها و راهنما در Dark Mode.
- کارت‌های شیشه‌ای با گرادیان و blur.
- حفظ نام مسیر تمام تصاویر موجود در نسخه قبلی.
- صفحه دستیار هوشمند با Sidebar اختصاصی چت.
- New Chat و ساخت Session ID مستقل برای هر گفتگو.
- Recent Chats مرتب‌شده بر اساس آخرین فعالیت.
- Pin Chat و بخش مستقل چت‌های پین‌شده.
- ذخیره sessionها در localStorage برای حفظ گفتگوها بین refreshها.
- ارسال `session_id` همراه درخواست `POST /api/chat` برای آماده بودن اتصال به Backend.
- سوال‌های آماده در شروع گفتگو بزرگ نمایش داده می‌شوند و پس از شروع چت به نوار کوچک بالای گفتگو منتقل می‌شوند.
- فضای مکالمه نسبت به پنل سوال‌ها بزرگ‌تر شده است.
- حذف Search، ساعت و مشخصات کاربر از نوار بالایی حفظ شده است.

## APIهای مورد انتظار

- `GET /api/dashboard`
- `POST /api/chat`
- `GET /api/customer-segments`
- `GET /api/customer-segments/{segment}/export`
- `GET /api/brand-intelligence`
- `GET /api/category-intelligence`

## تصاویر

تصاویر را با همان نام‌های نسخه قبلی داخل `public/assets/` قرار دهید. فایل راهنما در این پوشه نام فایل‌های مورد انتظار را فهرست کرده است.

## برند

نام، زیرعنوان و مسیر لوگو در ابتدای `src/main.jsx` داخل شیء `brand` متمرکز شده‌اند.
